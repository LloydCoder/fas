# Changelog

All notable changes to FAS are documented here.

The project follows a Keep-a-Changelog-style structure. Package version, Git tag, GitHub Release, and release notes should identify the same version.

## [Unreleased]

### Added

- Phase 16 bounded CycloneDX 1.7 supply-chain inventory normalization.
- Phase 15 deterministic security analyzer extension SDK and registry.
- Phase 14 deterministic evidence correlation groups and temporal evidence filtering.
- Phase 13 deterministic analysis query kernel.
- Documentation architecture aligned around tutorials, how-to guides, explanation, and reference.
- LLM-oriented documentation index and citation metadata.

### Changed

- Reworked the public README around product positioning, quick start, configuration, evidence semantics, and explicit capability boundaries.
- Reconciled Phase 1–16 implementation status with the 0.6.0 release boundary: Phases 13–16 are implemented on main but remain unreleased until a corresponding versioned release is published.
- Strengthened contributor, security, support, governance, and documentation guidance.

### Fixed

- Removed the contradictory uv.lock ignore rule.
- Clarified security reporting response targets and enforcement ownership.
- Corrected documentation navigation and ADR numbering ambiguity.

## [0.6.0] - 2026-10-01

### Added

- Phase 12 governed research maturity boundary.
- Phase 11 governance and assurance contracts.
- Phase 10 enterprise integration contracts and durable integration idempotency.
- Phase 9 controlled trusted runtime verification.
- Phases 1–8 foundational, production, and advanced analysis capabilities.
