## Bugs

Open a GitHub issue using the bug-report form:

https://github.com/LloydCoder/fas/issues

Include FAS version, Python version, operating system, command/API request, relevant configuration, minimal reproduction, expected behavior, actual behavior, and sanitized logs.

Never include credentials, customer information, private source code, or sensitive security evidence.

## Feature requests

Use the feature-request form. Explain the problem, affected workflow, why current capabilities are insufficient, and security/trust-boundary and compatibility implications.

## Security vulnerabilities

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Maintainer contact

For project-level questions that cannot be resolved through documentation or the issue tracker, contact **@LloydCoder via GitHub**.
