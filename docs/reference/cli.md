# CLI reference

Run <code>fas --help</code> for the complete current command surface.

| Command | Purpose |
|---|---|
| fas doctor | Diagnose the local runtime |
| fas tools | Inspect available external tools |
| fas analyze | Start an analysis |
| fas status | Inspect analysis status |
| fas findings | Inspect findings |
| fas report | Generate a report |
| fas api | Run the local API |
| fas verify | Inspect remediation-verification options |

Prefer <code>--format json</code> when scripting or integrating with other systems.
