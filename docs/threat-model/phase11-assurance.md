# Phase 11 assurance threats

Required invariants:
1. A control state is never stronger than its supporting evidence.
2. Missing evidence remains explicit.
3. Framework versions are immutable identifiers.
4. Bundle paths cannot escape the bundle root.
5. Bundle manifests are deterministic.
6. Bundle integrity is independently verifiable.
7. External signatures do not alter the underlying evidence manifest.
8. Governance metadata cannot override technical verdicts.
